  GET /api/stats                      → fetchStats()
  POST /api/sources                   → createSource()
  PATCH /api/sources/{id}             → updateSource()
  DELETE /api/sources/{id}            → deleteSource()
  POST /api/sources/{id}/toggle       → toggleSource()
  POST /api/sources/{id}/check        → checkSource()

Table Operations
  GET /api/sources/{id}/tables        → fetchSourceTables()
  GET /api/sources/{id}/preview/{name} → fetchTablePreview()
  POST /api/sources/{id}/query        → executeQuery()

File Operations
  GET /api/browse?mode=               → browsePath()

Import/Export
  GET /api/sources/export             → exportSources()
  POST /api/sources/import            → importSources()

MCP Configuration
  GET /api/mcp-config                 → fetchMCPConfig()
  POST /api/mcp-config/install        → installMCPConfig()

System
  GET /api/logs                       → fetchLogs()
  GET /api/auth/status                → fetchAuthStatus()
  POST /api/auth/configure            → configureAuth()
  GET /api/info                       → fetchSystemInfo()

All endpoints centralized in api.js for easy maintenance.

MIGRATION NOTES

To Use the Modular Version:

1. Build Setup
   Choose a build tool (Vite, Create React App, or Webpack):
   
   npm install
   npm run dev (for development)
   npm run build (for production)

2. Build Configuration
   Ensure your bundler:
   - Supports JSX
   - Supports ES6 modules
   - Outputs to /dist/index.html

3. Entry Point
   Your HTML should have:
   <div id="root"></div>
   <script src="path/to/bundled/index.js"></script>

4. Original File
   The production version stays at /dist/index.html
   Build output replaces it with bundled modular version

5. Testing
   After build, test all features in dist/index.html:
   - Add/edit/delete sources
   - Open detail panels
   - Run SQL queries
   - Test search and filters
   - Export/import
   - MCP config
   - Logs and settings
